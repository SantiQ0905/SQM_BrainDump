Brain Dump — Telegram Bot Glossary
====================================

BUCKET PREFIXES (route lines to specific buckets)
  i:  inbox (default if no prefix)
  t:  tasks
  n:  notes
  l:  links
  j:  journal
  a:  archive

TOKENS (inline markers parsed from text)
  [ ]       open task checkbox
  [x]       completed task checkbox
  !1        priority high (alias: !high)
  !2        priority medium (alias: !med)
  !3        priority low (alias: !low)
  ^date     due date
  @HH:MM    due time (appended to ^date, e.g. ^today@14:30)
  #tag      tag (lowercase, alphanumeric + hyphens/underscores)
  @project  project name (starts with letter, not confused with @HH:MM)

DATE SHORTCUTS
  ^today         resolves to today's date (YYYY-MM-DD, America/Monterrey TZ)
  ^tomorrow      resolves to tomorrow's date
  ^DD-MM         day-month, assumes current year
  ^DD-MM-YYYY    day-month-year
  ^YYYY-MM-DD    ISO format

TIME TOKENS (optional, appended to any date with @)
  ^today@14:30       due today at 2:30 PM
  ^tomorrow@09:00    due tomorrow at 9 AM
  ^2026-02-20@08:00  specific date and time
  Default: if no @HH:MM is given, due_time defaults to 09:00

REMINDERS
  When a task has a due date + time, you'll receive Telegram reminders at:
    - 1 hour before
    - 30 minutes before
    - 15 minutes before
    - 5 minutes before
  Reminders are checked every 5 minutes and deduplicated (sent only once each).

COMMANDS
  /start    welcome message + keyboard
  /help     show this glossary
  /brief    daily-style summary (inbox count, due/overdue tasks, top 5)
  /last     last 10 telegram captures
  /done     toggle most recent task from this chat (open <-> done)
  /done N   toggle the Nth most recent task (1-based)
  /del N    delete the Nth most recent item from this chat (1-based, required)

MULTI-LINE SUPPORT
  Paste multiple lines in a single message — each line is parsed
  and inserted independently. Lines can have different bucket prefixes.

  Example message:
    t: [ ] Buy groceries ^today@14:30 #errands
    n: The barista method works great
    l: https://example.com #reading

  This creates 3 separate entries: one task (due today at 2:30 PM),
  one note, one link.

SMART KEYBOARD
  The bot provides a persistent keyboard with common prefixes,
  tokens, and commands for quick input.

DAILY BRIEFS
  Morning brief (7 AM): Inbox count, due today, overdue, top 5 tasks.
  Evening brief (7 PM): Completed today, still open today, due tomorrow.
  Triggered automatically by cron. DST-aware (skips if local hour is off).

WEB NOTIFICATIONS
  Actions from the web UI (add, delete, toggle done) send a summary
  notification to all discovered Telegram chats, so you stay in sync
  even when using the web interface.
